Changes:
- Core native transformer uses nn.Module; VeOmni's outer PreTrainedModel owns HF metadata.
- Official parameter hierarchy is retained without a wrapper prefix.
- CUDA/SP source runtime and source LoRA/save/load wrappers are omitted from the backbone.
- Dense attention is expressed with PyTorch SDPA and identical boolean masks.
- Blocks use the Transformers GradientCheckpointingLayer contract.
- Standard tuple utilities replace hyvideo.commons imports.
- Frozen loading is local-only; glyph torch.load uses weights_only=True.
- VAE parallel-state import points to VeOmni; tile parallelism is not enabled.
- Formatting and unused imports are normalized to repository style.
- Adapter, condition orchestration, preprocessing, tests and dataset converter are new.

The source reference test executes pinned upstream bodies, with import/launch
dependencies isolated, and compares random-weight fp32 results and the full meta
parameter schema. Real pretrained checks and accelerator training remain pending.
